### Hi, I'm Ashwin

I build AI products that hold up in production. Mostly LLM agents, RAG and evals, plus the TypeScript and Python apps around them.

Right now I'm a founding engineer at Susanoox Digital, building AI products for clients in India, Saudi Arabia, the US and the UK. Before that I was at Richpanel, where I built Sidekick AI, an LLM copilot for customer support teams.

### Selected work

| Project | What it does | Built with |
| --- | --- | --- |
| **Sidekick AI** · Richpanel | Support copilot that drafts, summarises and translates replies, with an eval loop deciding what ships | Node.js, Pinecone, LLMs, PostHog |
| **Procura** | Procurement agent that reads RFPs, pulls past pricing and scores vendor quotes. Running for Nesma and Al Redaa | Tool-calling agents, PostgreSQL |
| **SPIC knowledge base** | RAG over fifty years of company records. Cites every answer and says so when it can't find one | RAG, OCR, multi-agent pipelines |
| **Kanakkan** | Ledger automation that sends easy transactions to a fast classifier and only the hard ones to an LLM | Jev, LLMs, GCP Pub/Sub, Go |
| **Accessiflow** | Turns scanned PDFs into accessible ones with proper tags, alt text and reading order | Python, Document AI, GCP |

These all live in private client repos. Happy to walk through any of them on a call.

### What I spend my time on

- RAG that cites its sources and admits when it doesn't know
- Tool-calling agents for real business workflows
- Evals, so a prompt change gets measured instead of guessed
- Routing cheap decisions away from expensive models
